# Avatar briefs (1 Nov 2026)

One avatar for each pillar of Vinco, to replace the line icons drawn in code. Each entry is the name in the app, its plain meaning, and a short brief to generate the art from. Generate every avatar with the shared style first, so the set reads as one family.

## Shared style (put this before every brief)

> A single emblem for a mobile app, Roman and Stoic in spirit, modern in finish. Centred, front or three-quarter view, on a transparent background. Flat shapes with one soft inner light and a fine engraved line, like a struck bronze or carved marble medallion. Palette: basalt dark brown (#1D1A17), marble cream (#ECE5D8), laurel gold (#D2AC55) as the only bright accent, porphyry red (#D0697D) only where the brief says so. No text, no letters, no numerals, no faces with expressions (helmets and masks stay calm). Reads clearly at 32 px and at 256 px. Square, 1024 by 1024.

Deliver each one twice: full colour, and a one-colour silhouette (for tinting by palette in the app).
