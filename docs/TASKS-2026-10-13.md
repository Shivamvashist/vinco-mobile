# Tasks: 13 Oct 2026 (Wave 3, front end)

The developer's brief of 13 Oct, planned and tracked here. Tick as done. Backend waits for the developer (see `../vinco-backend`).

## The brief, in short

1. **Onboarding starts from orders, not a campaign length.** Start, then "Your orders": suggested Water and Workout, a + to add your own (name, unit, how many: "Water", "glass", 12). One line: orders are done every day, no matter what. Primary: Continue (free training). Secondary: "Choose a campaign" (30, 60, 90 with Vinco's four). Then tone, oath ("Where do you see yourself in three months?", 90 days when no campaign), selfie.
2. **Today (Veni) is clean.** No quote line. Top: the user button (menu) and quick logs (selfie, weight, calories) that stand out until done today, then shrink. Scroll: orders, then to-dos. Done orders sink with a completion mark. Rows a little shorter.
3. **No orders yet:** the wake card, then a suggestion to add water. Outside a campaign, orders can be removed; no Truces, no loss; a gentle "keep your run" nudge instead.
4. **To-dos:** every day, or just today. A today task left undone moves to the next day by itself.
5. **User menu replaces the Settings tab:** account (coming), settings, permissions, orders and to-dos, guard and alarm, oath.
6. **Vidi:** calories as a second line on the weight chart, each line can be hidden. Tap a calendar day for a summary of that day.
7. **Fit real phones:** sizes scale with the screen width; text can grow with the phone's font size only so far.
8. **Sounds off by default**; the first selfie's seal, the oath lock and the conquest stamp always play.

## Decisions taken while planning

| Topic                      | Decision                                                                                                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Arc for "no campaign"      | Free training (`ludus`), with only the orders the user picked. Vinco orders per arc are the rows in `arc_orders`; a campaign has all four                                 |
| Own order form             | Name, unit, how many. Saved as min = full = how many. Up to 20 a day: a tap adds one, a hold takes one back. Bigger goals (steps): a tap opens a sheet to type the amount |
| Own orders limit           | 6 (was 4)                                                                                                                                                                 |
| A day with no orders       | Never held, never stamped                                                                                                                                                 |
| Wake-up outside a campaign | Not an order; the wake card still logs sleep each morning                                                                                                                 |
| Calories                   | `day_logs.calories` (whole kcal for the day), migration 0009                                                                                                              |
| Settings                   | A stack screen `/settings`, opened from the user menu. Tabs: Veni, Vidi, Vici                                                                                             |
| Notifications              | Local reminders work in Expo Go; remote push needs a development build (an APK, no Play Store)                                                                            |
